# LE OSINT Framework

Law-enforcement version of OSINT Framework: a tree of categories with links to free search sources only, in a spider-web style look, shared with colleagues by email. Hosted in the LE-OSINT-Framework repo on [[GitHub]].

Includes a searchable world ports and port-code list and a searchable HS customs code tab. Fits with [[Seizure Watch]] and [[Precursor Chemical ID]] in [[Law Enforcement Tools]].
