# LE OSINT Framework

**What it is:** a law-enforcement version of OSINT Framework: a tree of categories linking to search sources, for officers to use. Repo glretief-ux/LE-OSINT-Framework on [[GitHub]].

## How it works
- Free sources only, no paid sites.
- Spider-web style look, similar to OSINT Framework but not the same.
- Runs from a laptop and is shared with colleagues by email.
- Includes a searchable world ports and port-code list by country, and a searchable HS (harmonised) customs code tab.

## Decisions
- Free-only rule keeps it usable by any agency.
