# CEN Seizure Risk Board

**What it is:** a live dashboard (a claude.ai artifact) built from [[CEN Seizure Analysis]].

## How it works
- A refresh button loads a new Excel export, so updating needs no rebuild.
- Power BI-style look with the PCCP logo on top ([[PCCP House Style]]) and a drug-level slicer.
- Cases are scored with [[Risk Scoring]].

## Decisions
- Chosen over a public Pages site because the underlying data is sensitive and the repo stays private.
