# Whisky Dashboard

**What it is:** a YouTube analytics dashboard for [[Whisky Lovers Society]], adapted from the open-source Youtube-Dashboard repo by shriyaMadan. Private [[GitHub]] repo (glretief-ux/whisky-dashboard).

## How it works
- Pulls channel data from the YouTube Data API using an API key made in Google Cloud.
- Hosted on Render (free plan).

## Decisions
- Deployed from an iPad, so Render's web setup was used instead of anything needing a terminal.
