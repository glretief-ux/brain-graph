# CITES Timber ID

Public [[GitHub]] repo to help officers identify CITES-protected wood by genus, species and subspecies, with 10x end-grain photos.

- Searchable species lookup page ([[GitHub Pages Workflow]]), styled like [[Seizure Watch]].
- Current scope: CITES-protected wood in Africa.
- Goal: upload a 10x photo and have AI identify the wood, XyloTron-style.
- Specimens photographed with the [[Dino-Lite Microscope]]; a labelled demo model first, real model once open-source sample images are found.
- Related news category in [[Seizure Watch]].
