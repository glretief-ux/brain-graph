# CITES Timber ID

**What it is:** a public [[GitHub]] repo (glretief-ux/CITES-Timber-ID) that helps officers identify CITES-protected wood by genus, species and subspecies, with 10x end-grain (cross-section) photos.

## How it works
- A searchable species lookup page: type a scientific name and see everything known about it ([[GitHub Pages Workflow]]).
- Styled like [[Seizure Watch]] on purpose.
- Goal: upload a 10x photo and have AI identify the wood, in the spirit of XyloTron.
- Specimens are photographed with the [[Dino-Lite Microscope]].

## Decisions
- Scope narrowed to CITES-protected wood from Africa for now.
- Start with a labelled demo model while looking for open-source sample images for the real one.
- Own confirmed specimens are the ground truth.

## Open items
- Photograph more confirmed African specimens.
- Find open-source sample images and train the real model.
