# Lessons Learned

Working rules that came out of the projects.

- **Fewest steps first.** Default to the simplest option and offer depth as an upgrade ([[CEN Seizure Analysis]]).
- **Think iPad.** Anything that needs a terminal should have a web or app alternative ([[GitHub Pages Workflow]]).
- **Public repos are public.** Anything in a public repo, including this vault, can be read by anyone. Keep operational detail, case figures and private repo contents out of it ([[Brain Graph]]).
- **Explain the score.** Show why something is rated High ([[Risk Scoring]]).
- **Test where it runs.** Excel behaves differently from LibreOffice; code that cannot be executed in Claude's environment must be flagged as untested.
- **Reuse one look.** New tools copy the style of the previous ones ([[PCCP House Style]]).
