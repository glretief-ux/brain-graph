# GitHub Pages Workflow

How tools get published from an iPad: a repo on [[GitHub]], files uploaded through the website, Pages switched on (main branch /docs, or GitHub Actions), a GitHub Action to rebuild data.

Used by [[Seizure Watch]], [[CITES Timber ID]], [[Precursor Chemical ID]], [[LE OSINT Framework]] and [[Brain Graph]]. Tip: the website's "Add file" creates paths relative to the folder you are in, so check the folder first.
