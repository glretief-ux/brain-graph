# PCCP House Style

**What it is:** the shared look for decks, dashboards and bulletins, so everything reads as one family.

## The rules
- PCCP (AIRCOP / Container Control Programme) logo banner across the top.
- Verdana throughout, white background, blue and white accents on dashboards.
- Decks: first slide is a minimal base (full-width logo banner, page number only, no title). Title and content start on slide 2.
- Key facts as short on-slide bullets; the full explanation goes in the speaker notes; relevant photos on slides.
- Template decks: Empty_powerpoint.pptx, PCCP_Insider_Threat_-_ISPS_perspective.pptx and Port_Security_Icebreaker.pptx. The style is also packaged as the skill bundle pccp-house-style-deck.zip.
