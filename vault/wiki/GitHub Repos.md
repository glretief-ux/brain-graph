# GitHub Repos

All repositories on the GitHub account glretief-ux (state of 31 Oct 2026). Tooling for them is in [[GitHub]] and [[GitHub Pages Workflow]]. Hub: [[My Projects]].

**Public**
- **brain-graph** (https://github.com/glretief-ux/brain-graph): this second brain. Markdown notes in the vault folder become a graph, and Jarvis answers from them. Site: https://glretief-ux.github.io/brain-graph/ . See [[Brain Graph]] and [[Jarvis Services]].
- **Precursor-Chemical-ID** (https://github.com/glretief-ux/Precursor-Chemical-ID): identify drug precursors and chemicals by CAS, UN, HS code or name, and check the company on a sticker. Also holds the precursor chemicals course. Site: https://glretief-ux.github.io/Precursor-Chemical-ID/ . See [[Precursor Chemical ID]], [[Precursor Chemicals]] and [[Precursor Chemicals Course]].
- **Seizure-watch-** (https://github.com/glretief-ux/Seizure-watch-): the live daily open-source drug seizure news monitor with risk scores, daily bulletin and weekly route report. Site: https://glretief-ux.github.io/Seizure-watch-/ . See [[Seizure Watch]].
- **Sanctions-seizure-watch** (https://github.com/glretief-ux/Sanctions-seizure-watch): same template, for seizures where sanctions were in place (shadow-fleet tankers, dual-use goods, arms embargoes), with maps, routes and vessel lists. Includes a sanctions source registry. See [[Seizure Watch]].
- **LE-OSINT-Framework** (https://github.com/glretief-ux/LE-OSINT-Framework): an open-source intelligence desk for investigators with 690+ free resources in 50 categories, case playbooks, a suspect profile tool and a world ports directory. Site: https://glretief-ux.github.io/LE-OSINT-Framework/ . See [[LE OSINT Framework]].
- **CITES-Timber-ID** (https://github.com/glretief-ux/CITES-Timber-ID): field reference to screen CITES-listed wood at 10x hand-lens level, with species lookup and photos, plus a search of CITES-listed animals and plants. A screening tool, not a final identification. See [[CITES Timber ID]].
- **Seizure-watch** (https://github.com/glretief-ux/Seizure-watch): an earlier, empty repository. The live project is Seizure-watch- (with the trailing dash).

**Private**
- **CEN-nCEN-seizure-data**: exports of WCO CEN and nCEN seizure cases, kept private for version history. See [[WCO CEN nCEN Data]] and [[CEN Seizure Analysis]].
- **whisky-dashboard**: YouTube analytics dashboard for the whisky channel, hosted on Render. See [[Whisky Dashboard]] and [[Whisky Lovers Society]].
- **CITES-WOOD-AFRICA-**: private repository, apparently for the Africa-only wood data (I could not read it). See [[CITES Timber ID]].
